# GradeFlow AI V3 workflow

Question PDF + Answer Key PDF + 100 separate Student PDFs
→ selectable text extraction
→ Vision OCR when the PDF is scanned/handwritten
→ one independent grading call per student
→ name + roll number extraction
→ confidence/review flags
→ consolidated Excel result sheet.

A student PDF can contain 1, 3, 8, or more pages. The PDF remains one student record.
